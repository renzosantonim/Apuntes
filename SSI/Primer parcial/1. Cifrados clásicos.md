# 1.1 Vernam

## 1. Idea intuitiva
Vernam es el modelo más claro para entender un cifrado en flujo: al mensaje original se le combina una secuencia de bits de clave, bit a bit, usando XOR. La teoría lo presenta justo así: mensaje **M**, clave aleatoria **K** y texto cifrado **C = M XOR K.**

La idea mental es esta:
- tienes el mensaje en bits
- tienes una clave en bits
- haces XOR entre ambos
- obtienes el cifrado
Y para descifrar, vuelves a hacer XOR con la misma clave.

### One-Time Pad
Cuando la clave:
- es **verdaderamente aleatoria**
- tiene la **misma longitud que el mensaje**
- se usa **una sola vez**

Entonces Vernam se convierte en **One-Time Pad**, que tiene **secreto perfecto** según Shannon. Eso aparece explícitamente en la teoría.

## 2. Procedimiento paso a paso

### Para cifrar
1. Pasas el mensaje a binario.
2. Tomas una clave binaria de la misma longitud.
3. Haces XOR bit a bit.
4. El resultado es el texto cifrado.
### Para descifrar
1. Tomas el texto cifrado en binario.
2. Usas la misma clave binaria.
3. Haces XOR bit a bit otra vez.
4. Recuperas el mensaje original.

## 3. Qué significa “secreto perfecto”

Quiere decir que, si la clave cumple las condiciones del OTP (One Time Pad), el texto cifrado no da información útil sobre el texto original, ni siquiera a un atacante con recursos ilimitados. Es decir, proporciona un **secreto perfecto**.


# 1.2 Vigenère

## 1. Idea intuitiva
Vigenère es un cifrado de **sustitución polialfabética**.  
Eso significa que una misma letra del mensaje no siempre se cifra igual, sino que depende de la posición y de la letra de la clave que le toque en ese momento.

La teoría lo presenta como “el cifrado indescifrable” y explica que la 1.ª letra se desplaza k0 posiciones, la 2.ª k1​, etc., repitiendo la clave cuando hace falta. 

La idea mental es esta:
- conviertes letras en números
- conviertes la clave en números
- vas sumando o restando módulo el tamaño del alfabeto
- al terminar el alfabeto, vuelves a empezar

## 2. Conceptos mínimos

### Qué usa Vigenère

Usa:
- un **alfabeto ordenado**
- una **clave de varias letras**
- **aritmética modular**
### Cómo funciona

Cada letra del mensaje se desplaza según la letra de clave correspondiente.

Si la clave es, por ejemplo, **SOL**, entonces se repite así:

SOLSOLSOLSOL...

y se alinea con el mensaje.

donde:
- *Mi​ es la letra del mensaje en posición i*
- *Ci es la letra cifrada*
- *k(i mod r)​ es la letra de clave que toca*
- *m es el tamaño del alfabeto*
- *r es la longitud de la clave*

## 3. Procedimiento paso a paso

### Para cifrar
1. Escribes el mensaje.
2. Repites la clave hasta tener la misma longitud.
3. Transformas letras en números según el alfabeto.
4. Sumas:

***C = M + K (mod m)***

5. Vuelves de números a letras.

### Para descifrar
1. Escribes el texto cifrado.
2. Repites la clave hasta igualar la longitud.
3. Transformas letras y clave en números.
4. Restas:

***M = C − K (mod m)***

5. Vuelves a letras.

## 4. Muy importante: el alfabeto manda

En Vigenère **no existe un único alfabeto universal** para todos los ejercicios.  
Puede variar según diga la profesora:

- alfabeto de 26 letras
- alfabeto con **Ñ**
- alfabeto con **Ñ y sin W**
- otros formatos concretos

Y eso cambia completamente la numeración de las letras, así que, antes de hacer nada, siempre hay que preguntar:

**¿Qué alfabeto está usando el ejercicio?**

## 5. Ejemplo simple

Usamos alfabeto de 26 letras:

A = 0, B = 1, …, Z = 25

Queremos cifrar:

- mensaje: **SOL**
- clave: **DIA**

Convertimos:

- SOL → S = 18, O = 14, L = 11
- DIA → D = 3, I = 8, A = 0

Ahora sumamos módulo 26:

- 18 + 3 = 21 → V
- 14 + 8 = 22 → W
- 11 + 0 = 11 → L

Resultado:

SOL → VWL

Para descifrar, restaríamos módulo 26.

- 21 - 3 = 18 → S
- 22 - 8 = 14 → O
- 11 - 0 = 11 → L

## 6. Errores típicos

### Error 1: usar el alfabeto equivocado

Es el más peligroso.  
Si el ejercicio dice “con Ñ y sin W”, no puedes usar el alfabeto inglés normal.
### Error 2: no repetir bien la clave

Hay que alinearla exactamente con el mensaje.
### Error 3: hacer resta normal en vez de modular

Si sale negativo, no está mal: hay que corregir módulo m.

Por ejemplo:

2 − 5 = − 3

módulo 26:

−3 ≡ 23 (mod 26)
### Error 4: confundir cifrar con descifrar

- cifrar: **sumar**
- descifrar: **restar**
