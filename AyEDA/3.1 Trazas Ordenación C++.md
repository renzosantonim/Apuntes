# Trazas y Lógica en C++: Algoritmos de Ordenación

Este documento contiene las implementaciones clave en C++ de los algoritmos de ordenación más frecuentes, la explicación de cómo funcionan sus índices en la memoria, y las instrucciones exactas para invertir su orden lógico. Todo el código está adaptado al uso de `std::vector` y sigue estándares profesionales.

---

## 1. El Secreto del Sentido: ¿De Mayor a Menor o de Menor a Mayor?

Cambiar el sentido de la ordenación en cualquier algoritmo basado en comparaciones radica, casi exclusivamente, en **modificar el operador relacional** de la condición principal (el `if` o el `while`) que decide si se realiza un intercambio o un desplazamiento de memoria.

* **Ascendente (Menor a Mayor):** Buscas el elemento más pequeño para colocarlo a la izquierda, o empujas los grandes hacia la derecha.
* **Descendente (Mayor a Menor):** Inviertes la lógica. Buscas el elemento más grande para moverlo a la izquierda, o empujas los pequeños hacia la derecha.

| Algoritmo | Condición Ascendente | Condición Descendente |
| :--- | :--- | :--- |
| **Inserción** | `arr[j] > key` | `arr[j] < key` |
| **Selección** | `arr[j] < arr[min_idx]` | `arr[j] > arr[max_idx]` |
| **ShakeSort** | `arr[i] > arr[i + 1]` | `arr[i] < arr[i + 1]` |

## 2. Algoritmos Cuadráticos $O(N^2)$

### 2.1. Inserción (Insertion Sort)

**¿Cómo funciona? (La lógica de las cartas)**
* **El bucle `for` (i):** Selecciona el elemento que vamos a evaluar, al que llamamos `key`. Empieza en el índice 1, asumiendo que la "carta" en el índice 0 ya conforma nuestra parte ordenada.
* **El bucle `while` (j):** Va mirando hacia atrás y, si el elemento que evalúa es mayor que nuestra `key`, lo mueve una posición hacia la derecha (`arr[j + 1] = arr[j]`). Esto desplaza todo el bloque para crear un hueco perfecto.
* **El remate:** Al salir del `while`, el índice `j + 1` es el hueco exacto que hemos dejado libre, así que ahí insertamos la `key`.

```cpp
void insertionSort(std::vector<int>& arr) {
  int n = arr.size();
  for (int i = 1; i < n; ++i) {
    int key = arr[i];
    int j = i - 1;
    
    // ASCENDENTE: arr[j] > key
    // DESCENDENTE: arr[j] < key
    while (j >= 0 && arr[j] > key) {
      arr[j + 1] = arr[j];
      j--;
    }
    arr[j + 1] = key;
  }
}
```

#### Variante: Inserción por la Derecha
Si se pide insertar recorriendo desde el final hacia el principio del vector, la lógica de los bucles se invierte:

```cpp
void insertionSortRight(std::vector<int>& arr) {
  int n = arr.size();
  for (int i = n - 2; i >= 0; --i) {
    int key = arr[i];
    int j = i + 1;
    
    // Desplazamos hacia la IZQUIERDA los que rompen el orden
    while (j < n && arr[j] < key) {
      arr[j - 1] = arr[j];
      j++;
    }
    arr[j - 1] = key;
  }
}
```

### 2.2. Selección (Selection Sort)

**¿Cómo funciona? (El escaneo metódico)**
Es el que menos escrituras en memoria hace.
* **El bucle `for` externo (i):** Define la posición que queremos rellenar en esta pasada (la 0, luego la 1, etc.). Guarda este índice en `target_idx`.
* **El bucle `for` interno (j):** Escanea el *resto* del vector (desde `i + 1` hasta el final) buscando al verdadero candidato (el mínimo o máximo). Si encuentra uno mejor, actualiza `target_idx` con ese nuevo índice.
* **El remate:** Al terminar el escaneo, si el `target_idx` ha cambiado, hace un único `std::swap` para poner el número correcto en la posición `i`.

```cpp
void selectionSort(std::vector<int>& arr) {
  int n = arr.size();
  for (int i = 0; i < n - 1; ++i) {
    int target_idx = i;
    
    for (int j = i + 1; j < n; ++j) {
      // ASCENDENTE: arr[j] < arr[target_idx]
      // DESCENDENTE: arr[j] > arr[target_idx]
      if (arr[j] < arr[target_idx]) {
        target_idx = j;
      }
    }
    
    if (target_idx != i) {
      std::swap(arr[i], arr[target_idx]);
    }
  }
}
```

### 2.3. Sacudida (ShakeSort)

**¿Cómo funciona? (Ida y vuelta)**
Soluciona el problema de las "piedras" (números pesados mal ubicados) de la Burbuja.
* **Las paredes (`start` y `end`):** Definen los límites del vector no ordenado. Tras cada pasada, una pared se encoge.
* **La variable `swapped`:** Si damos una pasada y sigue en `false`, el vector ya está ordenado y el bucle termina antes de tiempo.
* **1ª pasada (Izquierda a Derecha):** Empuja el elemento más pesado hacia `end`. Luego hacemos `end--`.
* **2ª pasada (Derecha a Izquierda):** Empuja el elemento más ligero hacia `start`. Luego hacemos `start++`.

```cpp
void shakeSort(std::vector<int>& arr) {
  bool swapped = true;
  int start = 0;
  int end = arr.size() - 1;

  while (swapped) {
    swapped = false;
    
    // 1ª Pasada: De izquierda a derecha
    for (int i = start; i < end; ++i) {
      // ASCENDENTE: arr[i] > arr[i + 1]
      if (arr[i] > arr[i + 1]) {
        std::swap(arr[i], arr[i + 1]);
        swapped = true;
      }
    }
    
    if (!swapped) break;
    swapped = false;
    end--; 

    // 2ª Pasada: De derecha a izquierda
    for (int i = end - 1; i >= start; --i) {
      // ASCENDENTE: arr[i] > arr[i + 1]
      if (arr[i] > arr[i + 1]) {
        std::swap(arr[i], arr[i + 1]);
        swapped = true;
      }
    }
    start++; 
  }
}
```

## 3. Algoritmos Logarítmicos $O(N \log N)$

### 3.1. QuickSort (Partición de Hoare)

**¿Cómo funciona? (Divide y Vencerás In Situ)**
* **El Pivote:** Calculamos el valor del elemento físico central (`arr[(left + right) / 2]`).
* **Los exploradores (`i`, `j`):** El puntero `i` avanza desde la izquierda buscando números mayores o iguales al pivote. El puntero `j` avanza desde la derecha buscando números menores o iguales.
* **El Intercambio:** Cuando ambos se detienen y no se han cruzado (`i <= j`), se intercambian (`std::swap`) y dan un paso más.
* **Recursividad:** El vector queda partido en dos bandos. Se llama a la función para el bando izquierdo y el derecho.

```cpp
void quickSort(std::vector<int>& arr, int left, int right) {
  int i = left;
  int j = right;
  int pivot = arr[(left + right) / 2]; 

  while (i <= j) {
    // ASCENDENTE: arr[i] < pivot  ||  arr[j] > pivot
    // DESCENDENTE: arr[i] > pivot  ||  arr[j] < pivot
    while (arr[i] < pivot) i++;
    while (arr[j] > pivot) j--;
    
    if (i <= j) {
      std::swap(arr[i], arr[j]);
      i++;
      j--;
    }
  }
  
  if (left < j) quickSort(arr, left, j);
  if (i < right) quickSort(arr, i, right);
}
```

### 3.2. MergeSort (Ordenación por Mezcla)

**¿Cómo funciona? (La fuerza de la memoria auxiliar)**
* **La división (`mergeSort`):** Parte el vector por el medio (`mid`) recursivamente hasta tener trozos de 1 solo elemento (que ya están ordenados).
* **La mezcla (`merge`):** Recibe dos mitades ordenadas internamente.
  * Copia los datos a dos vectores temporales (`L` y `R`).
  * Usa punteros para comparar la cabecera de `L` con la de `R`. Toma el más pequeño (o el más grande, según el sentido) y lo sobreescribe en el vector original.
  * Vuelca cualquier remanente si uno de los dos vectores auxiliares se vacía antes que el otro.

```cpp
void merge(std::vector<int>& arr, int left, int mid, int right) {
  int n1 = mid - left + 1;
  int n2 = right - mid;
  
  std::vector<int> L(n1), R(n2);

  for (int i = 0; i < n1; i++) L[i] = arr[left + i];
  for (int j = 0; j < n2; j++) R[j] = arr[mid + 1 + j];

  int i = 0, j = 0, k = left;

  // Fase de fusión/mezcla ordenada
  while (i < n1 && j < n2) {
    // ASCENDENTE: L[i] <= R[j]
    // DESCENDENTE: L[i] >= R[j]
    if (L[i] <= R[j]) {
      arr[k++] = L[i++];
    } else {
      arr[k++] = R[j++];
    }
  }

  // Copia de elementos remanentes
  while (i < n1) arr[k++] = L[i++];
  while (j < n2) arr[k++] = R[j++];
}

void mergeSort(std::vector<int>& arr, int left, int right) {
  if (left >= right) return; 
  
  int mid = left + (right - left) / 2;
  
  mergeSort(arr, left, mid);      
  mergeSort(arr, mid + 1, right);  
  merge(arr, left, mid, right);    
}
```
