## **1. Introducción a los Árboles**

Un **árbol** es una estructura de datos **jerárquica**, compuesta por **nodos** y **aristas**.

- **Raíz**: nodo superior, punto de entrada.
- **Hijo**: nodo descendiente de otro nodo.
- **Padre**: nodo del que depende un hijo.
- **Hoja**: nodo sin hijos.
- **Altura**: número de niveles desde la raíz hasta la hoja más profunda.
- **Tamaño**: número total de nodos del árbol.

**Ejemplo visual básico:**

```cpp
       10 (raíz)
      /  \
     5    15
    / \     \
   2   7     20
```

- Raíz: 10
- Hojas: 2, 7, 20
- Altura: 3

---

## **2. Tipos de Árboles**

| **Tipo**                          | **Características**                                       | **Ejemplo**                     |
| --------------------------------- | --------------------------------------------------------- | ------------------------------- |
| **Binario**                       | Cada nodo tiene máximo 2 hijos (izquierdo y derecho)      | 10→5, 10→15                     |
| **Binario de Búsqueda (ABB/BST)** | Nodo izquierdo < nodo < nodo derecho                      | Inserción y búsqueda eficientes |
| **AVL**                           | ABB auto-balanceado con balance = altura_izq - altura_der | Garantiza O(log n)              |
| **N-ario**                        | Cada nodo puede tener hasta N hijos                       | Generalización de ABB (N=2)     |

---

## **3. Recorridos de Árbol**

- **Preorden:** Raíz → Izquierda → Derecha
- **Inorden:** Izquierda → Raíz → Derecha
- **Postorden:** Izquierda → Derecha → Raíz
- **Por niveles:** Nivel 0 → Nivel 1 → Nivel 2 …

**Ejemplo ABB:**

```cpp
       10
      /  \
     5    15
    / \     \
   2   7     20
```

- Preorden: 10, 5, 2, 7, 15, 20
- Inorden: 2, 5, 7, 10, 15, 20
- Postorden: 2, 7, 5, 20, 15, 10

**Tip visual de examen:**

- Dibujar el árbol y seguir la secuencia de flechas para marcar el recorrido ayuda mucho.

## **4. Árbol Binario de Búsqueda (ABB)**

### **4.1 Propiedades**

- Nodo izquierdo < nodo < nodo derecho
- Permite **búsqueda, inserción y eliminación eficientes**, promedio O(log n)

### **4.2 Inserción en ABB**

```cpp
class NodoBB {
public:
    int dato;
    NodoBB* izdo;
    NodoBB* dcho;
    NodoBB(int v) : dato(v), izdo(nullptr), dcho(nullptr) {}
};

void insertar(NodoBB* &nodo, int valor){
    if(!nodo) nodo = new NodoBB(valor);
    else if(valor < nodo->dato) insertar(nodo->izdo, valor);
    else insertar(nodo->dcho, valor);
}
```

### **4.3 Búsqueda en ABB**

```cpp
NodoBB* buscar(NodoBB* nodo, int valor){
    if(!nodo) return nullptr;
    if(valor == nodo->dato) return nodo;
    if(valor < nodo->dato) return buscar(nodo->izdo, valor);
    return buscar(nodo->dcho, valor);
} 
```

### **4.4 Eliminación en ABB**

Tres casos:

1. Nodo hoja → eliminar directamente
2. Nodo con un hijo → reemplazar por hijo
3. Nodo con dos hijos → reemplazar por **predecesor o sucesor** (el mayor del subárbol izquierdo o menor del derecho)

```cpp
void eliminar(NodoBB* &nodo, int valor){
    if(!nodo) return;
    if(valor < nodo->dato) eliminar(nodo->izdo, valor);
    else if(valor > nodo->dato) eliminar(nodo->dcho, valor);
    else { // encontrado
        NodoBB* aux = nodo;
        if(!nodo->izdo) nodo = nodo->dcho;
        else if(!nodo->dcho) nodo = nodo->izdo;
        else { /* sustituir por predecesor */ }
        delete aux;
    }
}
```

## **5. Árboles AVL – Balance y Rotaciones**

- ABB auto-balanceado: **balance = altura_izq - altura_der**
- Garantiza O(log n) siempre para búsqueda e inserción.

**Rotaciones:**

- **II:** Rotación simple izquierda
- **DD:** Rotación simple derecha
- **ID:** Rotación doble izquierda-derecha
- **DI:** Rotación doble derecha-izquierda

```cpp
void rotacion_II(NodoAVL* &nodo){
    NodoAVL* nodo1 = nodo->izdo;
    nodo->izdo = nodo1->dcho;
    nodo1->dcho = nodo;
    nodo = nodo1;
}
```


**Ejemplo visual:**

Antes rotación II:
```cpp
     30
    /
   20
  /
 10
```

Después rotación II:
```cpp
    20
   /  \
 10    30
```

## **6. Árboles N-arios**

- Cada nodo puede tener hasta **N hijos**
- Representación:

```cpp
template<class Key, int N>
class NodoN {
public:
    Key valor;
    NodoN* hijos[N] = {nullptr};
};
```

- N=2 → ABB generalizado
- N>2 → árboles de decisión, estructuras jerárquicas complejas

## **7. Recorridos y Ejemplos**

**Inorden (ABB) en pseudocódigo:**

```cpp
funcion inorden(nodo):
    si nodo es null, retorna
    inorden(nodo.izquierdo)
    imprimir(nodo.dato)
    inorden(nodo.derecho)
```

**Preorden y Postorden similares**, cambiando el orden de impresión y llamadas recursivas.

**Por niveles**: usar una **cola**:

- Insertar raíz con nivel 0
- Sacar nodo y procesar hijos, agregando nivel+1
- Repetir hasta que la cola esté vacía

## **8. Complejidad**

| **Operación** | **ABB promedio** | **ABB peor caso** | **AVL**  |
| ------------- | ---------------- | ----------------- | -------- |
| Inserción     | O(log n)         | O(n)              | O(log n) |
| Búsqueda      | O(log n)         | O(n)              | O(log n) |
| Eliminación   | O(log n)         | O(n)              | O(log n) |

## **9. Buenas prácticas y tips de examen**

- Inicializar punteros a `nullptr`
- Dibujar árboles antes de resolver ejercicios
- Usar recursión para recorridos, inserción y eliminación
- Entender bien las **rotaciones en AVL**
- Recordar diferencias **ABB vs AVL vs N-ario**
- Complejidad promedio y peor caso
